# 3. Quelles données Masterix peut-il traiter ?

Les données accessibles par un bot Discord dépendent notamment des permissions qui lui sont accordées et des interactions effectuées avec lui.

Discord indique notamment que les bots peuvent accéder, selon leur configuration, à certaines informations de base relatives aux membres d’un serveur, aux rôles, aux métadonnées des messages, aux salons vocaux et aux réactions.

Dans le cadre de son fonctionnement, Masterix peut notamment traiter certaines des catégories suivantes.

### 3.1 Identifiants Discord

Masterix peut traiter certains identifiants nécessaires à son fonctionnement, tels que :

- l'identifiant Discord d’un utilisateur ;
- l'identifiant Discord d’un serveur ;
- l'identifiant Discord d’un rôle ;
- l'identifiant Discord d’un salon ;
- l'identifiant Discord d’un message lorsque cela est nécessaire à une fonctionnalité.

Ces identifiants permettent notamment à Masterix de savoir à quel utilisateur, serveur, rôle ou salon une configuration ou une action est associée.

# 4. Informations de profil Discord

Selon les fonctionnalités utilisées et les informations rendues accessibles par Discord, Masterix peut traiter certaines informations de profil ou d’identification visibles sur Discord, notamment :

- nom d’utilisateur ;
- surnom sur un serveur ;
- avatar ;
- rôles ;
- informations nécessaires à l’identification d’un membre dans le cadre d’une commande.

Masterix n’a pas pour objectif de créer des profils comportementaux des utilisateurs ou de déterminer leur identité réelle.

Les données API Discord ne doivent pas être utilisées à des fins incompatibles avec les fonctionnalités déclarées de l’application. Les politiques développeurs de Discord interdisent notamment le profilage des utilisateurs Discord à partir des données API.

---

# 5. Données liées aux commandes

Lorsqu’un utilisateur utilise une commande Masterix, le Bot peut traiter les informations nécessaires à l’exécution de cette commande.

Cela peut notamment comprendre :

- l’identifiant de l’utilisateur ;
- l’identifiant du serveur ;
- l’identifiant du salon ;
- les paramètres transmis à la commande ;
- les informations nécessaires à l’exécution de l’action demandée.

Certaines commandes peuvent nécessiter la lecture d’un message ou de son contenu afin de comprendre la commande demandée.

Masterix ne doit pas utiliser les données obtenues via Discord pour des finalités étrangères à ses fonctionnalités déclarées.

---

# 6. Données de modération et de sécurité

Certaines fonctionnalités de Masterix sont destinées à la modération et à la sécurité des serveurs.

Dans ce cadre, Masterix peut traiter des informations nécessaires pour :

- détecter certains comportements abusifs ;
- appliquer des mesures de modération ;
- gérer des systèmes anti-raid ;
- gérer des sanctions ;
- produire des logs ;
- identifier l’utilisateur concerné par une action ;
- assurer le fonctionnement des mécanismes de sécurité.

Les informations enregistrées peuvent notamment comprendre des identifiants Discord et les informations nécessaires pour comprendre ou documenter l’action concernée.

---

# 7. Système de blacklist

Masterix dispose d’un système de blacklist globale.

Lorsqu’un utilisateur est placé sur cette blacklist, certaines informations peuvent être conservées afin de permettre au Bot d’appliquer la restriction.

Cela peut notamment comprendre :

- l’identifiant Discord de l’utilisateur ;
- les informations nécessaires à la gestion de la blacklist ;
- les informations relatives à la raison de la mesure lorsque celle-ci est enregistrée ;
- les informations nécessaires à la gestion administrative de la sanction.

La blacklist sert exclusivement à empêcher l’utilisation de Masterix lorsque l’accès a été retiré au niveau global.

Elle ne constitue pas une sanction Discord et ne modifie pas le compte Discord de l’utilisateur.

---

# 8. Système d'accès

Masterix peut conserver les informations nécessaires à son système d’accès par serveur.

Cela peut notamment comprendre :

- les identifiants des utilisateurs autorisés ;
- les identifiants des rôles autorisés ;
- l’identifiant du serveur concerné.

Ces données servent à déterminer si un utilisateur possède l’autorisation nécessaire pour utiliser certaines fonctionnalités protégées.

Un utilisateur autorisé dans un serveur ne bénéficie pas automatiquement d’un accès dans un autre serveur.

# 12. Logs

Certaines actions peuvent être enregistrées dans les systèmes de logs configurés par le serveur.

Les logs peuvent être utilisés afin de :

- faciliter la modération ;
- assurer la sécurité ;
- détecter des comportements abusifs ;
- conserver une trace d’une action administrative ;
- diagnostiquer un problème technique ;
- permettre aux administrateurs du serveur de comprendre les actions réalisées.

Les logs Discord éventuellement envoyés dans un salon de logs restent également accessibles aux membres disposant des permissions Discord permettant de consulter ce salon.

Le propriétaire du serveur est responsable de la configuration de ses salons de logs et des personnes auxquelles il donne accès.
